# Machine Learning Project: Weather Prediction

## Overview

The aim of this project is to develop different machine learning approaches for predicting the temperature in Bern, the capital of Switzerland, at 12-, 24-, and 48-hour forecasting horizons, based on various meteorological characteristics measured across the country, and to compare their performance in order to identify the one providing the most accurate temperature forecasts. The project involves not only evaluating the predictive performance of established machine learning models, but also developing a more sophisticated two-stage approach by combining two different models in a sequential manner and addressing the technical challenges arising from this approach.
